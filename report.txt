2 Statistical Methods
Each hypothesis follows an identical pre-specified decision pipeline:
1. Build the DV at the participant level from trial-level data.
2. Compute full descriptive statistics (n, M, SD, Mdn, Q1, Q3, min, max) per group.
3. Test normality within each group using Shapiro–Wilk.
4. Test variance homogeneity using Levene’s test, median-centred (= Brown–Forsythe).
5. Select the test:
• Both groups normal and equal variance ⇒Student’s t-test
• Both groups normal and unequal variance ⇒Welch’s t-test
• Either group non-normal ⇒Mann–Whitney U test (two-sided)
6. Report effect sizes: Cohen’s d / Hedges’ g for parametric tests; rank-biserial r for non-
parametric tests.
7. No correction for multiple comparisons is applied. All reported p-values are raw.
2.1 Accuracy dependent variable
All accuracy-based DVs use raw proportion correct (range 0–1). Chance performance is 0.5
in a two-alternative forced-choice task.

11 Regression Analysis
11.1 Overview and Feature Policy
A strict, assignment-style regression pipeline was applied to predict trial-level recognition accuracy
(resp.corr, binary) from pre-response design variables and pre-treatment participant covariates.
Post-response variables (RT, confidence) were explicitly excluded to prevent data leakage. Two
participants who failed the vigilance check (sub105_AB, sub70_NB) are excluded throughout.
• Included (pre-response): condition, target_type, is_repeat, movie_duration, stimulus_id
• Optional controls (pre-treatment): age, gender, handedness, vision
• Excluded (leakage / post-response): resp.rt, conf_radio.response, conf_radio.rt

predictors, using (successes, failures) counts as the response. This model provides a participant-

11.6 Mixed-Effects Logistic Regression (GLMM)
11.6.1 Rationale and Model Specification
Because each participant completed 40 trials, observations are not independent. A mixed-effects
(multilevel) logistic regression addresses this in two ways simultaneously:
• Random intercept for participantid — controls for stable baseline accuracy differences
between individuals (e.g., some people are simply better at the recognition task).
• Random intercept for movieid — controls for differences in how memorable or difficult
individual clips are, preventing hard/easy movies from inflating or deflating condition estimates.
Using random intercepts for both levels produces a crossed random-effects structure: each
participant is exposed to movies from their condition, and each movie is seen by multiple
participants. This is the most principled approach for this fully balanced design.
Formal model.
logitP(correctij ) = β0 + β1 ABi + β2 is_repeatij + β3 agei + β4 malei + ui + wj
ui ∼N(0, σ2
participant)
wj ∼N(0, σ2
movie)
where iindexes participant and j indexes movie. Estimation used variational Bayes (statsmodels
BinomialBayesMixedGLM). Approximate z-statistics and p-values are derived from the normal
distribution using posterior means divided by posterior SDs.

11.6.4 Summary
The mixed-effects logistic regression provides the most methodologically rigorous answer to
the primary research question. After controlling for individual participant ability and clip-
level memorability, Abrupt Boundary (AB) cutting significantly reduces recognition
accuracy relative to Natural Boundary (NB). The effect is robust: OR≈0.74, a ≈26% reduction
in odds, p < .001. This converges with the GEE Model 1 estimate (OR=0.775) and the
participant-level H1 result, establishing consistency across all three levels of analysis.
