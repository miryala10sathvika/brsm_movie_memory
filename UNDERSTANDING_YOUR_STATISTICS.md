## CALCULATING ADDITIONAL USEFUL METRICS

### **Percentage Improvement**
```
Relative improvement = (NB - AB) / AB × 100
                     = (0.872 - 0.838) / 0.838 × 100
                     = 4.06%
```
**Use:** "NB condition improved accuracy by 4% relative to AB baseline"

---

### **Coefficient of Variation (CV)**
```
CV = (SD / Mean) × 100

NB: CV = (0.069 / 0.872) × 100 = 7.9%
AB: CV = (0.084 / 0.838) × 100 = 10.0%
```
**Use:** "AB group showed 26% more relative variability (CV=10.0%) than NB (CV=7.9%)"

---

### **Effect Size Estimation (Cohen's d)**
```
Cohen's d = (M₁ - M₂) / Pooled SD

Pooled SD = sqrt[((n₁-1)×SD₁² + (n₂-1)×SD₂²) / (n₁+n₂-2)]
          = sqrt[((79-1)×0.069² + (67-1)×0.084²) / (79+67-2)]
          = sqrt[(0.371 + 0.465) / 144]
          = sqrt[0.0058]
          = 0.076

Cohen's d = (0.872 - 0.838) / 0.076
          = 0.447 (MEDIUM effect size)
```
**Interpretation:** Medium effect (Cohen's benchmarks: 0.2=small, 0.5=medium, 0.8=large)

---

### **Number Needed to Treat (NNT) - Practical Impact**
```
NNT = 1 / (Rate₁ - Rate₂)
    = 1 / (0.872 - 0.838)
    = 1 / 0.034
    = 29.4

Round down to: NNT = 29
```
**Interpretation:** For every 29 people who view natural boundaries instead of abrupt cuts, one additional person will achieve high recognition accuracy.

## CONFIDENCE INTERVALS (Alternative to significance tests)

### **95% CI for Mean Accuracy:**

```
CI = Mean ± (1.96 × SE)
SE = SD / sqrt(n)

NB: SE = 0.069 / sqrt(79) = 0.0078
    95% CI = 0.872 ± (1.96 × 0.0078) = [0.857, 0.887]

AB: SE = 0.084 / sqrt(67) = 0.0103
    95% CI = 0.838 ± (1.96 × 0.0103) = [0.818, 0.858]
```

**Interpretation:**
- 95% confident that true NB accuracy is between 85.7% and 88.7%
- 95% confident that true AB accuracy is between 81.8% and 85.8%
- **CIs do NOT overlap at 85.8%** → suggests meaningful difference
